# Les fonts del SOS

Space Grotesk i JetBrains Mono, en `woff2` variable (pesos 400–700), subconjunts
`latin` i `latin-ext`, tal com les serveix Google Fonts. Viuen aquí perquè l'app
no depengui de cap servidor de fora per arrencar (`pla-millora-sos.md`, punt 1).

Llicència: SIL Open Font License 1.1 — `OFL-SpaceGrotesk.txt` i
`OFL-JetBrainsMono.txt`.
