# Diagnòstics d'UX del SOS

Cada carpeta és una passada: `captura-ux.mjs` fa captures de totes les
pantalles de l'app (escriptori i mòbil) amb les seves mesures, i
`diagnosi-ux.mjs` les fa mirar a la IA amb tres ulls (qui hi arriba nova, qui
coordina cada dia i una dissenyadora de producte) i n'escriu l'informe.

Es llança des d'Actions → «Banc de proves de la IA» amb `eina: diagnosi-ux`.
Les captures queden com a artefacte de l'execució; aquí només l'informe
(`informe-ux.md`), el diagnòstic per pantalla i l'inventari.
