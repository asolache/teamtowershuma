# SOP · Revisar les intuïcions periòdicament

## Objectiu

Mantenir el mapa Johari viu — les intuïcions canvien, en venen de noves,
n'hi ha que es perden si es deleguen massa. Revisió cada 3 mesos.

## Pre-requisits

- Mapa Johari inicial (output del SOP anterior)
- 3+ mesos d'operació amb el sistema actual de delegació
- 2+ observadors externs accessibles

## Passos

1. **Re-llegir el mapa actual**: què hi és, què s'ha confirmat, què
   ha quedat obsolet?

2. **Comprovació amb observadors**: les mateixes 2-3 persones del SOP
   inicial, pregunta'ls: "Hi ha alguna intuïcio meva que abans
   notaves i ara potser ja no notes?" (alerta d'erosió per delegació).

3. **Afegir noves intuïcions** que hagis detectat aquests mesos
   (especialment les que apareixen quan algú et felicita per alguna
   cosa "fàcil").

4. **Actualitzar decisions de delegació**: si una intuïcio s'ha
   erosionat, *re-internalitza*-la (no la deleguis aquest trimestre).

5. **Documentar canvis**: el mapa Johari té versió. v1 → v2 → v3.
   Cada versió amb data i resum dels canvis.

## Criteris d'èxit

- Mapa Johari actualitzat amb canvis documentats
- Almenys 1 conversa amb observador extern per cicle
- Decisions de delegació re-validades

## Errades a evitar

- **No revisar**: el mapa fossilitza i les decisions de delegació es
  basen en informació obsoleta
- **Confondre estabilitat amb fossilització**: una intuïcio sòlida es
  manté; una sense ús desapareix
- **No detectar erosió**: si una intuïcio "ja no la notes" i la deleguies,
  l'has perduda. Recuperar-la triga mesos.
