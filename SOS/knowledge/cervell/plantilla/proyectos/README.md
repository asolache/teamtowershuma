# Proyectos

Lo que tiene principio y fin: un encargo, un lanzamiento, una edición. Una
carpeta por proyecto (`proyectos/<nombre>/`), con documentos que llevan la
cabecera del tronco común.

Cuando un proyecto acaba no se mueve: sus documentos pasan a `estado: superado`
y siguen donde estaban, para que ningún enlace se rompa. Lo que aprendió va al
codex o a su área.
