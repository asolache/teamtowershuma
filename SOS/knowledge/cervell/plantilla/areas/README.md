# Áreas

Lo que se mantiene siempre, ordenado por las áreas de cualquier organización.
Una carpeta por área que se use, con su nombre en el idioma del cerebro:

| Carpeta | Qué entra |
|---|---|
| `estrategia/` | Visión, gobierno, el mapa de valor y las decisiones grandes |
| `comunicacion/` | Marca, relato, prensa, blog y redes |
| `marketing/` | Mercado, públicos, posicionamiento, web y campañas |
| `ventas/` | Clientes, oferta, catálogo y embudo |
| `finanzas/` | Presupuesto, costes, cobros, subvenciones y tesorería |
| `logistica/` | Proveedores, compras, espacios y transporte |
| `produccion/` | Lo que se hace: contenido, desarrollo, elaboración |
| `operaciones/` | El día a día: entregas, eventos, procesos, calidad y soporte |
| `personas/` | Equipo, formación, cuidados y horas |
| `red/` | Socios, alianzas y comunidad |
| `sistemas/` | Herramientas, datos, automatizaciones e IA |
| `legal/` | Contratos, RGPD y normativa |

Son los doce roles de `saber/heredado/taxonomia-universal.json`, que resumen
las áreas del APQC Process Classification Framework. La guarda falla si aquí
aparece una carpeta que no es ninguna de ellas. Una carpeta aparece cuando
entra su primer documento: no se crean vacías.

Cada documento lleva la cabecera del tronco común (ver `saber/taxonomia.md`).
