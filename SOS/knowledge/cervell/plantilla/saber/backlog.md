# Backlog

La fuente de verdad del desarrollo. Cada bloque dice **quién lo pidió, cuándo,
qué se pide y cómo se cierra**. Cada PR fusionado se cierra aquí con lo medido.

## Pendiente

### Ejemplo · el primer bloque (pedido AAAA-MM-DD)

**Pedido por:** quien sea. **Qué:** lo que dijo, con sus palabras.
**Cómo se cierra:** la comprobación que lo demuestra.
