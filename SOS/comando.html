Com et convertiràs en superheroi

Tres passos. Un minut. Cap servidor. La teva identitat es queda al teu dispositiu.

1

Obre SOS al teu navegador

Zero descàrrega. Local-first. Es genera automàticament la teva identitat did:sos (Ed25519, W3C SubtleCrypto). La clau privada mai surt del dispositiu.

2

Crea el teu cromo

Nom + població + fins a 5 superpoders (skills) + superarmes (objectes que poses en comú). El sistema et vincula al banc de temps + biblioteca del teu barri.

3

Puja de nivell

Aprenent → Bronze → Plata → Or → Llegenda. Cada intercanvi firmat, cada objecte compartit, cada molekulon activat suma XP. Els reptes del següent tier són visibles al teu cromo.

🔐 Registre descentralitzat · sense servidor

El teu perfil superheroi és portable i verificable per contracte tècnic. Ningú el pot alterar sense la teva firma.

  • did:sos — identifica't amb un DID W3C generat pel teu navegador. Compatible amb l'ecosistema descentralitzat.
  • WebAuthn passkey — vincula un passkey del teu dispositiu (Face ID, Touch ID, Windows Hello) per accés + recuperació.
  • NIP-05 alias (backlog) — reclama nom@teamtowershuma.com per fer-te trobable via Nostr sense donar el DID sencer.
  • WebRTC P2P — sincronitza el teu perfil entre dispositius directament, sense passar per cap servidor.
  • Anthropic BYO-key — quan uses IA (kit narratiu, valoració, matching), tu poses la clau. Zero SaaS de TeamTowers.
  • GitHub OAuth device flow — vinculació opcional per revisar PRs col·laboratius del codex.
