Integración de IA en Acción

Cuando un rol tiene un servicio de IA configurado, el asistente puede:

  • Responder preguntas técnicas usando el modelo especializado (ej: DeepSeek para código)
  • Generar entregables basados en patrones del conocimiento
  • Sugerir valores para nuevos entregables según el contexto
  • Analizar redes de valor y proponer optimizaciones

Ejemplo de Enrutamiento en el Chat

Usuario: "@deepseek, ¿cómo implemento un vesting de 4 años con cliff de 1 año en Solidity?"

Sistema: Detecta @deepseek → Enruta a DeepSeek API → Muestra respuesta en el chat

Seguridad y Privacidad

⚠️ Advertencia Importante: Las API Keys se almacenan en localStorage de tu navegador. Esto significa:

  • Solo tú tienes acceso a estas claves en este dispositivo
  • Nunca se envían a servidores de TeamTowers Humà
  • Usa claves con permisos limitados y monitorea su uso
  • Para máxima seguridad, considera usar un proxy backend

Cómo Funciona

Cuando un usuario pregunta "@deepseek, ¿cómo implemento un contrato de vesting?" en el chat:

  1. El sistema detecta la mención @deepseek
  2. Busca el rol en la base de conocimiento
  3. Encuentra la configuración de IA asociada
  4. Envía la pregunta a la API de DeepSeek
  5. Muestra la respuesta en el chat con contexto del conocimiento local
